# СВЧ лабараторные работы

## Лабараторная работа №3 (MaterialUI)

Вопросы:
* Что лучше использовать: 'import { } from "path"' или 'import Ex from "path/Ex"'

Компоненты используемые из MaterialUI:
1. Container (NotFoundPage, SliderUSM) - обьединение элементов (централизованные)
2. Box (NotFoundPage, SliderUSM) - обьединение элементов  (подержка css в sx)
3. ErrorOutlineIcon (NotFoundPage) - иконка ошибки
4. Typography (Header, NotFoundPage, CardUSM) - текст в соответсвии рекоменлации Material
5. AppBar (Header) - header компонент
6. Drawer (BM) - меню для навигации
7. Toolbar (Header) - контейнер примущественно для AppBar 
8. IconButton (Header)- кнопка в виде иконки
9. MenuIcon (Header) - набор иконок
10. Button (NotFoundPage, SliderUSM) - готовый компонент кнопки
11. Table (TableAboutGramma) - таблица с стилистикой MaterialUI
12. TableHead (TableAboutGramma) - заголовок таблицы для MaterialUI
13. TableBody (TableAboutGramma) - тело таблицы для MaterialUI
14. TableRow(TableAboutGramma) - строка в таблице
15. TableCell(TableAboutGramma) - ячейка таблицы
16. Dialog(Header) - создает диалог
17. DialogTitle(Header, SliderUSM) - заголовок диалога
18. DialogContent (Header, SliderUSM) - соддержимое диалога
19. DialogActions(Header, SliderUSM) - контейнер для компонентов событий (закрытие, сохранение и тд)
20. Card (CardUSM)
21. CardContent (CardUSM)
22. AddIcon (CardUSM, SliderUSM)
23. TextField (SliderUSM)
24. DeleteIcon (SliderUSM)
25. EditIcon (SliderUSM)
